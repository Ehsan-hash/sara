Welcome! Set up Sara

This server has no owner yet. Set it up now to become its owner.

Where do I find the setup code?

Open the app's log in your server's dashboard and look for "setup code":

CasaOS or ZimaOS: the app's menu (⋮), then Logs.

TrueNAS: Apps, then Sara, then the logs icon under Workloads.

Unraid: Docker, click Sara's icon, then Logs.

Docker: docker compose logs sara

The code is new at every start. If it timed out, restart the app and use the new one.

Or sign in with the owner token

Enter the owner token printed in the server log on first start.

Where do I find it?

On the server, run the line for how you installed her, then copy the long code it shows:

Windows or Mac installer: its last page showed it (with a Copy button).

Linux installer: sudo journalctl -u sara | grep -A1 'owner token'

Docker: docker compose logs sara | grep -A1 'owner token'

Lost it? Make a new one: Linux sudo sara reset-token; Windows or Mac sara reset-token (on Windows in a terminal opened as administrator when she runs as a service); Docker docker compose exec sara node src/main.ts --reset-token, then docker compose restart sara.
